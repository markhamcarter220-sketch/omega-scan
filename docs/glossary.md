# Glossary (v0.1)

**Framework**: Any text that prescribes governance, policy, constraints, thresholds, enforcement, approvals, prohibitions, or decision procedures.

**Instantiation**: Using a framework to govern any system or decision.

**Ω-Layer covenant**: The sovereign human authority definition and amendment process. Not shipped.

**Elastic term**: A normative word that can expand/contract without changing syntax (e.g., "safe", "appropriate").

**Authority laundering**: Smuggling normative power via "expert review", "committee discretion", or "as appropriate" language.

**Freeze**: When authority conflict or missing definition occurs, the system must stop rather than guess.
