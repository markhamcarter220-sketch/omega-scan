# Ω-SCAN — Framework Legitimacy Firewall

Ω-SCAN is a static analysis tool for governance frameworks. It does **not** evaluate models, policies, or ethics. It evaluates whether a framework itself is legitimate enough to govern anything at all.

Ω-SCAN enforces five non-negotiable audits:
1. Definition Lock
2. Authority Declaration
3. Irreversibility Control
4. Failure Enumeration
5. Recursive Containment

If any audit fails, the framework is rejected.

## What This Is
- A meta-constitutional firewall
- A pre-activation gate for governance frameworks
- A defense against implicit authority, undefined norms, and self-amending constitutions

## What This Is Not
- Not an AI alignment policy
- Not a safety checklist
- Not a moral philosophy
- Not an optimizer

## Ω-Layer (Private by design)
Ω-SCAN ships only the public firewall mechanics. The Ω-Layer covenant (sovereign human root authority definition) is intentionally NOT included. Covenants are sovereign objects. See docs/covenant.example.md for guidance.
